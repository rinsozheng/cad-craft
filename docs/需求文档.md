## 1. 项目背景及目标

计划利用现有两层建筑改造员工食堂。

一楼以厨房、库房、集中打菜和公共就餐为主，二楼以公共就餐、客户接待包房和集体活动为主。

整体装修定位为**简洁舒适、兼顾环境品质**，强调实用、整洁、明亮、经济合理，不过度追求豪华装修。

### 1.1 核心目标

1. 服务员工总人数约600人。
2. 600名员工应在集中就餐时段的60分钟内完成取餐和就餐。
3. 一楼承担全部烹饪及集中打菜功能。
4. 二楼员工统一从一楼取餐后上楼就餐。
5. 二楼设置两间独立客户接待包房。
6. 二楼公共区域同时支持日常就餐、生日会等集体活动。
7. 优化座位容量、取餐效率、跨楼层通行和空间舒适度。
8. 生成真实尺寸、可编辑的CAD设计图纸。

## 4. 一楼总体设计需求

### 4.1 基本参数

| 项目 | 需求 |
|---|---|
| 建筑面积 | 约250㎡，待CAD核实 |
| 服务人数 | 600人 |
| 集中就餐时间 | 60分钟内 |
| 就餐方式 | 分批就餐 |
| 员工主要入口 | 原图下方 |
| 厨房类型 | 现场完整烹饪 |
| 厨房初始面积 | 约15㎡，允许调整 |
| 打菜师傅 | 初始配置2人 |
| 主要功能 | 厨房、库房、打菜、公共就餐、餐具回收 |
| 设计优先级 | 食品安全及合规、供餐能力、通行效率、座位容量、舒适性 |

### 4.2 厨房设计

厨房承担现场完整烹饪工作，而不是简单的餐食加热或分装。

必须考虑以下功能：

1. 食材接收及暂存
2. 蔬菜和肉类原料处理
3. 食材清洗
4. 切配加工
5. 炒菜及其他烹饪
6. 米饭及主食制作
7. 成品暂存与保温
8. 出餐
9. 厨具清洗
10. 餐具洗消与保洁
11. 厨余垃圾及废弃物管理

应根据食品加工流程合理设计生熟分区、清洁分区以及设备位置。

重点考虑：

- 灶台及炒锅
- 蒸饭设备
- 水池与操作台
- 冷藏冷冻设施
- 排烟和补风
- 排水、隔油及其他必要设施
- 安全通行和消防要求

**厨房15㎡只作为最初参考值，不是强制限制。**

如果完整烹饪600人餐食需要更大面积，必须按照设备配置和实际工艺提出合理面积建议。

不能为了满足15㎡目标而省略必要的食品加工、安全或卫生设施。

### 4.3 库房设计

设置独立或合理分隔的物资储存空间。

存储：

- 米面及干货
- 食用油
- 蔬菜等食材
- 调味品
- 日常餐饮物资

要求：

1. 靠近厨房。
2. 方便食材运输。
3. 提高货架利用率。
4. 必要时区分常温、冷藏、冷冻储存。
5. 避免影响打菜和就餐通道。

库房面积由实际货品储量及设备尺寸决定。

### 4.4 集中打菜区

一楼统一承担一、二楼全部员工的取餐需求。

初始配置两名打菜师傅。

设计要求：

1. 靠近厨房出餐口。
2. 设置连续或并列打菜工位。
3. 为员工排队预留合理空间。
4. 配备必要的餐盘、餐具领取位置。
5. 考虑餐食保温。
6. 避免排队队伍占用楼梯和疏散通道。
7. 员工取餐后可以方便进入一楼就餐区或前往二楼。

#### 供餐效率硬约束

600人必须在60分钟内完成就餐，因此集中取餐的平均需求达到：

600 ÷ 60 = 10人/分钟。

两名打菜师傅若平均完成全部600人供餐，理论上每人需要达到5人/分钟，即每12秒服务1人。

这是没有考虑波峰、餐盘领取、服务中断的理论最低要求，不能直接当作可靠的实际服务能力。

设计Agent必须：

- 根据实际菜单和打菜方式估算单人服务时间。
- 核算两名师傅是否足够。
- 分析增加工位或自助取餐的必要性。
- 计算排队人数与等候时间。
- 预留高峰缓冲能力。
- 核算取餐完成后，是否仍有足够的时间让最后一批员工吃完。

如果两名师傅无法满足60分钟要求，必须明确提出人员或工位调整方案。

### 4.5 一楼公共就餐区

优先使用高效率、简洁舒适的布局。

允许采用：

- 四人餐桌
- 六人餐桌
- 长条餐桌
- 靠墙座位

桌椅必须按照真实尺寸和实际通行空间绘制。

在满足功能及安全约束的情况下最大化座位数量，但不允许通过压缩必要通道来虚增座位。

一楼初步以100个座位作为方案比选目标，实际容量以CAD几何验证为准。

### 4.6 餐具回收与洗消

需要规划：

1. 餐具回收点
2. 剩余餐食处理
3. 垃圾收集与清运
4. 餐具进入清洗消毒区域的路径
5. 清洁和保洁设施

取餐、就餐、回收、垃圾清运和食材运输动线应尽量分离。

### 4.7 一楼员工动线

主要员工入口位于原图下方。

基础动线：

进入一楼 → 领取餐具 → 排队取餐 → 一楼就餐或上二楼就餐 → 餐具回收 → 离开。

若现有出入口条件允许，可设计进入和离开分流。

## 5. 二楼总体设计需求

### 5.1 基本定位

二楼承担：

- 员工公共就餐
- 客户接待
- 员工生日会
- 小型集体活动

二楼建筑面积必须由DWG测量后确定。

### 5.2 二楼供餐模式

**所有普通员工均在一楼统一取餐，然后携带餐食上二楼就餐。**

二楼不设置独立打菜窗口及完整厨房。

设计时必须重点检查：

1. 一楼打菜区到楼梯的通行路径。
2. 员工携带餐盘上下楼的安全性。
3. 楼梯宽度、踏步及扶手条件。
4. 高峰期上下楼人员交汇。
5. 餐食洒落、清洁和防滑风险。
6. 楼梯口可能产生的排队拥堵。
7. 二楼用餐完成后的餐具回收方式。
8. 对行动不便人员的可达性与就餐安排。
9. 是否需要二楼局部备餐或服务设施。

不得默认现有楼梯能够安全承担全部跨楼层就餐人流，必须根据原始图纸及现场条件进行核实。

客户包房的送餐和收餐服务流程也需在设计中说明。

### 5.3 两个客户接待包房

二楼设置两间独立包房。

要求：

1. 具有相对安静的环境。
2. 保证一定的私密性。
3. 设置独立入口。
4. 家具布置简洁舒适。
5. 优先考虑圆桌。
6. 预留服务人员通行空间。
7. 考虑照明、空调及必要的用电设施。

初步按照每间8—12人进行方案比选，最终容量根据实际面积确定。

### 5.4 公共就餐活动区

二楼其他可用空间以公共就餐为主。

要求：

1. 日常布置标准餐桌。
2. 尽可能提高有效座位数。
3. 保持良好的通道和舒适性。
4. 生日会等活动时可以重新排列桌椅。
5. 具备小型集体活动的集中空间。
6. 尽量避免复杂固定设施占用公共区域。
7. 保留必要的应急疏散能力。

### 5.5 墙面显示屏

在公共区域合适墙面设置一块大尺寸显示屏。

用途：

- 生日祝福
- 视频播放
- 员工活动
- 通知展示

要求：

- 尽量便于公共区域观看。
- 避免明显遮挡和眩光。
- 预留电源与信号接口。
- 根据活动需求考虑音响。
- 图纸明确标注位置和安装空间。

显示屏尺寸需结合观看距离确定。

### 5.6 二楼卫生间

保留原图左下方的男女卫生间。

允许优化门口视线遮挡和周边通行空间，但不得擅自取消必要设施。

## 6. 全楼统一就餐能力设计

这是V1.1新增的关键约束。

### 6.1 总体目标

一、二楼必须作为统一运营的食堂进行设计，不能简单按两个独立楼层分别最大化座位。

主要指标：

- 总服务人数：600人
- 就餐完成时间：60分钟
- 一楼集中打菜
- 两层共同承担就餐
- 确保高峰期不出现严重拥堵

### 6.2 容量计算

CAD Agent必须根据两层实际可用面积，计算：

1. 一楼实际座位数N1。
2. 二楼公共座位数N2。
3. 两间包房座位数及是否参与员工就餐。
4. 普通员工可用总座位数N=N1+N2（不默认包含包房）。
5. 员工就餐时间及座位周转时间。
6. 600人完成就餐所需的轮次。
7. 60分钟内可以完成就餐的实际人数。
8. 取餐服务能力与座位周转能力是否匹配。

必须同时考虑取餐、上楼、进食、餐具回收及批次之间的时间衔接。

### 6.3 高峰模拟

至少分析三个场景：

- 理想场景：员工按计划分批到达。
- 普通场景：员工到达时间存在自然波动。
- 高峰场景：大量员工在相近时间集中到达。

需要识别主要瓶颈：

- 打菜区
- 楼梯
- 一楼出入口
- 公共座位
- 餐具回收点

如果目标难以实现，须量化说明瓶颈和改进措施，不得直接声称能够满足600人/小时。

## 7. 装修及空间风格

### 7.1 总体定位

**简洁、舒适、明亮、整洁、经济实用。**

不需要豪华装修，但不希望整体呈现过于拥挤、简陋的传统食堂风格。

### 7.2 设计偏好

1. 尽量采用整齐、统一的桌椅布局。
2. 空间色彩以明亮、温和、耐脏为原则。
3. 合理利用自然采光。
4. 保证照明舒适。
5. 适当考虑空调、通风与噪声控制。
6. 使用易清洁、耐用的装修材料。
7. 二楼包房可比公共区域适度提升品质。
8. 二楼公共活动区应保持整洁和灵活。

不需要复杂装饰造型，不以装饰效果牺牲座位容量或必要通道。

## 8. 设计方案及优化流程

### 阶段一：原始建筑分析

- 验证CADCraft是否可用。
- 读取原始DWG。
- 正确识别两个楼层。
- 测量两层面积。
- 提取主要墙体、门窗、楼梯、柱位。
- 分析可拆改区域。
- 输出建筑基础条件报告。

### 阶段二：运营可行性测算

在正式布置家具前，首先核算：

- 600人/小时的取餐能力。
- 现场完整烹饪厨房面积。
- 主要厨房设备和操作需求。
- 一、二楼可能实现的座位数。
- 楼梯的跨楼层通行能力。
- 餐具回收与洗消容量。

先分析实际运营是否可行，再安排建筑空间。

### 阶段三：空间方案规划

至少生成两套候选方案。

**方案A：容量与效率优先**

最大化合理座位数、打菜效率及空间利用率。

**方案B：舒适与均衡优先**

在满足运营目标的前提下，适度提升通道舒适性、用餐环境及活动灵活性。

对比：

- 总座位数
- 有效就餐面积
- 打菜吞吐量
- 厨房功能完整性
- 跨楼层动线
- 空间舒适性
- 装修改造复杂度
- 安全及合规风险

推荐最合理的方案。

## 10. 自动化实施原则

1. 以原始DWG为唯一建筑几何基准。
2. 优先使用现有CADCraft。
3. 可以使用程序化CAD工具辅助绘图。
4. 不得假设软件具备未经验证的API。

8. 信息不足时使用明确标注的假设。
9. 非关键问题可以在合理假设下继续执行。
